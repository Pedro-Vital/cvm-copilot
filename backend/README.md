# CVM Copilot — backend

FastAPI service. See [`CLAUDE.md`](CLAUDE.md) for conventions and [`../docs/architecture.md`](../docs/architecture.md) for design.

## Setup

```bash
cd backend
uv sync
cp .env.example .env   # fill in Supabase + OpenAI values
```

## Run

```bash
uv run uvicorn app.main:app --reload
```

Check it's alive:

```bash
curl http://localhost:8000/health
# {"status":"ok"}
```

## Test & lint

```bash
uv run pytest -m "not integration"
uv run ruff check .
```

## Migrations

```bash
uv run alembic revision --autogenerate -m "<change>"
uv run alembic upgrade head
```

Always review autogenerated migrations before applying — see `CLAUDE.md`.
